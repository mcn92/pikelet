What is Pikelet?

Pikelet is an open-source (Apache-2.0) tool that compiles a folder of documents or a website into one self-contained, queryable .pikelet file. The file carries the source text, a semantic (vector) index and a BM25 keyword index, the query encoder that turns a question into a vector, evaluation queries, and integrity hashes over all of it. Its identity is a SHA-256 hash of its contents, so an answer can cite the exact version of the knowledge it came from.

Put the file on disk, S3, R2, a CDN or any static HTTP host. A reader opens it locally or over HTTP Range requests and searches it with no vector database, embedding API or search server: it loads a small index, embeds the question with the encoder inside the file (WebAssembly, in the browser or Node.js), and fetches only the byte ranges it needs. Updates ship as small immutable layer files on top of a base file.

What this page shows

  • Search: the page mounts wikipedia.pikelet, 456,153 Simple English Wikipedia articles in one 648.5 MB file on Cloudflare R2, and answers each question in your browser, listing every byte range it reads. There is no /search, /embed or /api endpoint behind it.
  • Remove a fact: small packs that are identical except for one record, removed in one and edited in another, answer the same question. The answer follows the file's contents and nothing else.

Grounding

Each answer carries grounding: the words of the question that the best-matching of the top five passages contains, and the ones it lacks. If the thing you asked about is in the lacking list, that passage does not state it. It is not a fact-check: a passage that contains every word can still be wrong or out of date, so read it before relying on it. Pikelet used to add a calibrated relevance verdict; measured on real questions it did not help, and 0.15.0 dropped it.

Use it

npx pikelet compile --source ./docs --out docs.pikelet
npx pikelet mcp install --client claude-code --pack ./docs.pikelet

The first command builds a pack from a folder or a URL; the second gives Claude Code, or any MCP client, a search tool over it. From code, openPikeletFile in the pikelet-wasm package opens a pack in Node.js, browsers or Cloudflare Workers; the CLI is the pikelet package.

Source, documentation and benchmarks: github.com/mcn92/pikelet.
