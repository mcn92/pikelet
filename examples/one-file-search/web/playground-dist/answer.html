A language model that answers from the file.

Your question is searched in wikipedia.pikelet, the same 648.5 MB static file as the search page. The top three passages go to SmolLM2, a small open language model running in this tab on WebAssembly, which answers from them. Nothing is sent to a server: the file is read with byte ranges, and the model runs on your CPU.

How this works

  • Search: pikelet's browser reader embeds your question with the encoder inside the file and range-reads the nearest passages, as on the search page.
  • Model: SmolLM2 (Hugging Face, Apache-2.0), quantized to 8 bits, on a dependency-free WebAssembly kernel from pikelet's decoder spike. It uses several threads when the browser allows it, and gives the same answer, token for token, at any thread count.
  • Prompt: the three passages and your question, with an instruction to answer only from them, or to say the passages don't contain the answer.
  • Limits: these are small models. In testing on 70 questions written from this pack's passages, the 360M model answered 54 correctly from the top three passages, against 2 with no passages. It can still misread a passage or answer when it shouldn't, so check the passages below the answer.
